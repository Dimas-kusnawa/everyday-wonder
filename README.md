A program that writes one line of everyday wonder to `/output/entry.txt` (135 characters, inside the 200-character cap). The fridge hums the same low note every night, and the wonder only arrives when the hum stops — the silence makes the whole kitchen feel like it had been holding its breath.

## Run it

```sh
python3 main.py
```
